# BLUI 桌面画布使用说明

桌面画布是基于 Blender 原生节点编辑器、文件浏览器和窗口系统的可选组件。它提供透明文件图标、分组、小工具和底部任务栏，不会自动替换 Windows Shell，也不会自动隐藏 Windows 桌面或任务栏。

## 打开与操作

从 BLUI 组件菜单打开“桌面画布”。顶栏“添加文件”可导入文件引用，目录框和刷新按钮可读取目录；刷新不会重置已经手动排列的图标。文件、快捷方式和文件夹图标透明显示，Windows 图标提取在独立辅助进程中进行，尚未加载或提取失败时显示原生备用图标。

- 单击选择，Shift 多选；双击打开文件或文件夹。空白处按住左键拖动框选，松开完成；也可按 B 进入框选，Escape／右键取消。中键平移、滚轮缩放，拖动或 G 移动图标；Home 查看全部，数字键盘小数点查看所选。
- “画布”菜单或右键菜单提供文件操作和“更多”系统菜单。Ctrl+C、Ctrl+X、Ctrl+V、F2 分别是复制、剪切、粘贴和重命名；实际文件操作复用文件管理器的后台队列。
- X、Delete 或“移除卡片（保留文件）”只移除桌面引用，不删除磁盘文件。“删除到回收站”才会操作真实文件，并要求确认。
- “添加图标面板”创建原生 Frame。将图标放入面板可整体整理；Ctrl+G 创建真正的节点组，Tab 进入、Ctrl+Tab 返回、Alt+G 解组。组内图标仍然指向原文件。
- 从文件管理器拖入画布会添加引用；跨桌面窗口拖动图标会移动引用，按 Ctrl 拖动则复制引用。拖到文件夹属于真实文件操作，遵循文件管理器的冲突检查，不会悄悄覆盖已有文件。

节点位置的撤销需要启用 Blender“全局撤销”。撤销桌面排版不等于撤销磁盘文件的复制、移动、重命名或回收；操作真实文件前请核对目标。

## 多显示器与布局恢复

“显示器”菜单可打开某个显示器的桌面，或“一次打开所有显示器桌面”。每个显示器使用独立布局；当前实现针对物理多显示器，不是 Windows 虚拟桌面管理器。N 打开侧栏，可修改桌面名称、查看显示器绑定和保存状态。

布局有变化时约每 30 秒异步保存全部桌面，包括图标位置、面板、组、小工具和背景设置；主文件采用同目录原子替换，并保留上一次有效的 `.bak` 备份。重启可恢复已保存布局，主文件损坏时尝试有效备份。突然断电或崩溃仍可能丢失最后一次保存之后的改动，请在重要排版后使用“保存布局”。

存储位置是 BLUI 用户配置目录下的 `blui_desktop`，多屏布局文件为 `displays.json`。布局保存的是路径引用，不是文件内容的备份。文件被外部移动、删除或盘符变更后，需要刷新并重新指向正确路径。

显示器插拔、主屏或 DPI 变化时，BLUI 检测拓扑变化并尝试将自己的桌面窗口恢复到可见区域；断开显示器的布局保留，重新连接后可再次打开。它不改变系统分辨率，也不移动其他程序窗口。进行拖动、文本编辑等交互时，异步更新会延后应用，避免清除仍在使用的原生节点数据。

## 背景图

在“画布 → 选择桌面背景”选取 PNG 或 JPEG；N 侧栏的“桌面 → 桌面背景”可设置启用、重新加载、移除、布局、透明度及水平/垂直对齐。每张显示器桌面可单独设置背景。

布局包括适应、填充、拉伸、居中、平铺和跨显示器。“跨显示器”按照物理显示器位置取图；各屏使用同一张图片和相同布局参数时才会连续显示。对齐滑块的 -1／0／1 分别对应左／中／右、下／中／上。

保留 PNG 自身透明通道，透明度为 0–100%。透明区域露出的是 BLUI 画布，不是让 Windows 窗口穿透到系统桌面。源文件上限 64 MiB、源图上限约 3200 万像素，显示纹理限制约 400 万像素；较大的支持图片会缩小，以限制内存占用。解码在独立进程中进行。移除背景不删除原图，修改源图片后可点击重新加载。

## 小工具

“BLUI”或“画布 → 小工具”可添加时钟、计算器和天气卡片。小工具可以移动、缩放排版、放入面板和节点组，其设置随布局保存。

- 时钟显示系统本地时间；选中后可在节点属性中调整时间、日期格式。
- 计算器提供数字键盘和表达式输入，支持常用算术及列出的数学函数。它使用有长度、深度和计算量限制的解析器，不执行 Python 脚本。
- 天气默认关闭联网。选择预设城市或填写经纬度，再启用“在线天气”或点击刷新；城市文字只是显示名称，不会自动定位用户。联网后所选坐标发送给第三方天气服务，不使用 IP/GPS 自动定位。

天气使用 [Open-Meteo](https://open-meteo.com/en/docs)，可选其托管的 [中国气象局 CMA GRAPES 模型](https://open-meteo.com/en/docs/cma-api)。显示的是模型估计值，不是气象站实测值。缓存刷新周期约 15 分钟，单次请求超时 6 秒；离线时保留旧数据及原更新时间，不伪装成实时天气。不能保证中国所有地区和网络都能连接该服务。

Open-Meteo 的[免费托管服务条款](https://open-meteo.com/en/terms)限制非商业用途，数据按 CC BY 4.0 署名，卡片保留来源信息。商业部署应另行核实服务授权和用量。

## BLUI 与 Windows 任务栏

画布底栏是原生 UI：组件入口、窗口列表、所有任务菜单、文件操作状态和时钟。窗口列表支持激活与最小化；Windows 的前台权限可能拒绝某些自动激活，高权限且身份无法核实的窗口只读显示。

如需隐藏原有任务栏，在底栏“BLUI”菜单显式选择“隐藏 Windows 任务栏”；同一菜单的“恢复 Windows 任务栏”随时可恢复。默认不隐藏。隐藏前先持久记录本次隐藏的窗口身份，两个独立辅助进程负责恢复；正常退出、主进程异常退出、守护进程失败或 UI 心跳超时会尝试恢复。若仍提示恢复待完成，请使用恢复入口；无法保证系统或 Explorer 自身故障时立即恢复。

此操作只处理本次识别并记录的 Windows 任务栏，不修改自动隐藏设置、注册表或系统工作区，也不结束 Explorer。当前底栏不是完整的 AppBar，不接管系统通知区、开始菜单或所有系统托盘功能。

机制参考 [RetroBar](https://github.com/dremin/RetroBar) 及其使用的 [ManagedShell](https://github.com/cairoshell/ManagedShell)，重点是窗口身份核实、原任务栏可恢复以及多屏适配。RetroBar 使用 Apache-2.0 许可；本轮是设计参考，并未直接移植其 WPF 任务栏或声称具有其全部功能。

## 视频编辑器的独立范围

每个视频编辑器顶栏有自己的“编辑器起始／结束”帧；也可在 N 侧栏“视图 → 编辑器播放范围”调整。“范围”菜单可按选中条带设置或重置当前编辑器范围。这些范围不再修改其他视频编辑器的范围。

独立的是当前编辑器的时间线/播放范围，场景播放头、视频条带内容和场景数据仍共享，不是独立剪辑工程或多路同时播放。开始播放时会取得该编辑器范围的快照；播放中修改范围，在下次播放时生效。

本轮不会恢复 UV 编辑器，也不会覆盖旧发布目录。桌面组件仍是渐进式原生桌面方案，不能视为已经完整替代 Windows 资源管理器、桌面和系统任务栏。
